# Palier · Révision plongée N1-N3

Site de présentation de **Palier**, une app iPhone en français pour réviser la théorie des niveaux de plongée du
Niveau 1 au Niveau 3 (N1, PE40, N2, PE60, N3) : leçons courtes, quiz corrigés, révisions espacées, examen blanc et
Méga Quiz pour les soirées club. La mascotte est un poisson-globe au masque relevé, qui gonfle quand on se trompe.

Palier est une application indépendante et non officielle, ni éditée ni validée par la FFESSM.

Site : https://prunob.github.io/palier/
